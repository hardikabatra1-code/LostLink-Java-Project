# LostLink

## Project Description
LostLink is a console-based Java application that helps users report lost and found items and connect rightful owners with people who find those items.

## Technologies
- Java
- MySQL
- JDBC
- Git and GitHub

## Team Structure

| Member | Responsibility |
|---|---|
| Member A | User management, authentication, database connection and integration |
| Member B | Lost and found item management |
| Member C | Item matching and recovery verification |

## Project Modules
- User Management
- Authentication
- Lost Item Reporting
- Found Item Reporting
- Item Searching
- Matching
- Recovery Verification

## Database
Database name: lostlink_db
